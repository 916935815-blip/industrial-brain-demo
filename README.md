# Industrial Brain — Scenario Demo

Landing page for the Industrial Brain (data ontology + multi-agent collaboration) demo, with 6 desensitized factory scenarios.

- Hosted on GitHub Pages: https://<username>.github.io/<repo>/
- Single static HTML, no dependencies, no backend, no API keys.
- URL params: ?sc=0~5&auto=1 auto-play a scenario; &noanim=1 disables animations for clean recording.
